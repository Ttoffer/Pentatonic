Pentatonic Circle + Guitar Fretboard

Key: E • Minor Pentatonic

Five patterns (CAGED)

Each key uses five connected boxes. Pattern 1 is the home box (tonic on the low E). Click a box to start there, then add the next pattern(s) up the neck.

Overlays

Pick a starting pattern.

Circle (click a key)

Tap a key to hear that note on the low E string (standard tuning).

Fretboard (Strings labelled at the nut)

Tap a labelled note or any empty fret to hear that string and fret.

Pull-off pair
Five CAGED boxes: pick a starting pattern, then show the next one along the neck. Shared notes are the link. Turn on pull-off pairs to see whole-step neighbours on a string (one middle fret between them — not the 3-fret stretch).

iPhone & iPad

For the best experience and to add an icon to your home screen, use Safari (not Chrome or another browser for this step).

  1. Open Safari and go to https://ttoffer.github.io/Pentatonic/
  2. Tap the Share button (square with an arrow).
  3. Scroll and tap Add to Home Screen.
  4. Edit the name if you like, then tap Add.

You’ll get an icon that opens without Safari’s address bar, like a small app. Repeat on each device you use.

Tip: If the site or icon updates and something looks old, remove the home screen shortcut and add it again from Safari.
